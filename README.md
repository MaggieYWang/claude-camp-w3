# Claude Camp W3 练习说明
本目录包含 3 个 Python 小程序：CSV 学员数据分析器，JSON 配置文件读写器，字符串工具库及单元测试。以下说明各自功能、运行环境和使用方法。

## 1. CSV 学员数据分析器
### 功能介绍
| 功能 | 说明 |
|------|------|
| 读取数据 | 自动读取本地 users_data.csv 文件 |
| 数据清洗 | 自动处理空邮箱、统一日期格式、统一国家名称大小写 |
| 统计总人数 | 统计 CSV 中学员总数 |
| 统计各国人数 | 按国家分组统计人数，从高到低排序展示 |
| 统计对赌完成率 | 统计 bet_status 为 completed 的学员比例 |
| 本地保存 | 自动将统计结果保存至本地 report.json 文件 |
| 数据加载 | 程序启动时自动加载上次保存的统计结果 |
| 友好提示 | 输入无效选项时，程序不会崩溃，会给出提示 |

### 运行环境
- Python 3.6 及以上
- 依赖第三方库 pandas，安装方式：

```bash
pip install pandas
```

### 使用方法
1. 将 `users_data.csv` 放在与脚本相同的目录下
2. 运行程序

```bash
python "CSV Student Data Analyzer.py"
```

3. 根据菜单提示输入选项，示例如下：
```
==============================
     学员数据分析器
==============================
1. 统计总人数
2. 统计各国人数
3. 统计对赌完成率
0. 退出
------------------------------
请输入选项：
```

### CSV 格式要求
输入文件需包含以下列：
| 列名 | 说明 | 示例 |
|------|------|------|
| name | 学员姓名 | Alice |
| email | 邮箱地址 | alice@example.com |
| joined_date | 加入日期 | 2026-05-01 或 May 1, 2026 |
| country | 所在国家 | Singapore |
| bet_status | 对赌状态 | active / completed / pending / inactive |

## 2. JSON 配置文件读写器
### 功能介绍
| 功能 | 说明 |
|------|------|
| 加载配置 | 程序启动时自动加载本地 config.json 文件 |
| 菜单选择 | 在窗口中输入编号选择要修改的设置项 |
| 数据验证 | 输入无效值时程序不会崩溃，会给出提示 |
| 保存配置 | 修改后自动将设置保存回本地 config.json 文件 |

### 运行环境
- Python 3.6 及以上
- 无需安装任何第三方库，使用 Python 内置功能即可运行

### 使用方法
1. 运行程序
```python "JSON_Config_Manager.py"```

2. 根据菜单编号选择要修改的设置项
3. 输入新的值，程序将自动验证并保存，示例如下：

```
==============================
     JSON 配置文件读写器
==============================
请选择你要修改的设置：
1. 主题
2. 语言
3. 字体大小
4. 字体颜色
5. 自动保存
6. 自动保存间隔
7. 日期格式
0. 退出
------------------------------
请输入你的选项：3
请输入新的字体大小：999
❌ 不能大于 32
请重新选择
```

## 3. 字符串工具库及单元测试

### 功能介绍
| 功能 | 说明 |
|------|------|
| 输入文本 | 在窗口中输入英文文本 |
| 反转单词顺序 | 将输入文本中的单词顺序反转输出 |
| 统计元音字母 | 统计文本中所有元音字母（a, e, i, o, u）的数量 |
| 判断回文 | 判断输入文本的单词顺序正反是否一致 |

### 运行环境
- Python 3.6 及以上
- 无需安装任何第三方库，使用 Python 内置功能即可运行

### 使用方法
#### 运行主程序
1. 运行程序
```
python string_utils.py
```

2. 根据提示输入一段英文文字
3. 程序将自动输出以下结果，示例如下：

```
请输入一段文字：you can you
反转单词顺序：you can you
元音字母数量为：5
这段文字是回文
```
#### 运行测试
1. 确保已安装 pytest
```
pip install pytest
```

2. 在项目目录下运行测试
```
pytest test_string_utils.py -v
```

3. 所有测试通过后将显示以下结果：
```
test_string_utils.py::test_reverse_words PASSED
test_string_utils.py::test_count_vowels PASSED
test_string_utils.py::test_is_palindrome PASSED

3 passed in 0.11s
```
